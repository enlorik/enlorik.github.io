01 Features
TIMELINE

Contest Calendar

Weekly view of upcoming and live Codeforces contests. Color-coded by type — CF, IOI, ICPC. Toggle individual events and persist your preferences across sessions.

CF IOI ICPC
BOUNTY BOARD

Active Contests

Card grid of all active and upcoming Codeforces contests. Each card shows type, phase, and start date. One click to jump straight to the contest page.

REAL-TIME DATA
DAILY

Problem Recommendations

One problem per algorithm tag, personalised to your current rating. Filters out problems you've already solved. Selection rotates daily by UTC date — same picks all day, every day different.

PROFILE

Local Handle Storage

Set your Codeforces handle once. Stored in localStorage — no account, no backend, no tracking. Daily Problems uses it to fetch your rating and exclude solved problems.
