01 Features
TIMELINE

Contest Calendar

Weekly view of upcoming and live Codeforces contests. Color-coded by type — CF, IOI, ICPC. Toggle events and persist preferences across sessions.

CFIOIICPC
BOUNTY BOARD

Active Contests

Card grid of all active and upcoming contests. Each card shows type, phase, and start date. One click to jump to the contest page.

REAL-TIME DATA
DAILY

Problem Recommendations

One problem per algorithm tag, personalised to your rating. Filters out solved problems. Rotates daily by UTC date — same picks all day, new ones tomorrow.
